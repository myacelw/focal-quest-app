# 个人信息保护影响评估（简版）

日期：2026-07-25 · 版本：迭代 3b-2 · 评估人：开发者（家长本人）

本文件为 spec §7.5 要求的一页纸留档。App 定位是**儿童视力训练的记录与引导工具**，
不提供医疗诊断、不作疗效承诺。

## 1. 处理活动

| 项 | 内容 |
|---|---|
| 主体 | 个人开发者（家长），自研自用，未商业化 |
| 处理的信息 | 家长邮箱；训练记录（日期/时长/答对数/反应时间）；打卡与积分；勋章与图鉴；奖励兑换记录；家长手动录入的验光视力值 |
| **不处理** | 孩子真实姓名、生日、性别、照片、录音、位置、通讯录、设备标识符 |
| 目的 | 仅多设备同步与防丢；无画像、无广告、无第三方统计 |
| 法律基础 | 监护人明示同意（注册时勾选，不同意不影响任何功能） |
| 存储地点 | Cloudflare D1（境外节点） |
| 保留期限 | 至账号删除；本地数据由监护人自行清除 |

## 2. 风险与缓解

| 风险 | 等级 | 缓解措施 |
|---|---|---|
| 儿童信息属敏感个人信息 | 高 | 数据最小化：档案只存昵称，不收上表"不处理"的任何一项 |
| 数据出境（服务器在境外） | 中 | 家用规模、不含身份标识；商业化前迁回国内（spec §2.6 已列为触发条件） |
| 账号被抢注（一期无邮箱验证） | 中 | 归属制邀请码把风险限定在持码者内；开放注册前必须接邮件验证 |
| 数据库泄露导致密码被破 | 中 | 密码不上传：客户端 PBKDF2 310000 次拉伸，服务端再加盐 SHA-256；token 只存哈希 |
| 会话令牌泄露 | 低 | 令牌只存设备本地 Dexie，服务端仅存哈希；导出的备份文件不含令牌 |
| 弱密码（客户端是唯一能校验强度的地方） | 中 | 本地强制 ≥8 位（`sync/credentials.ts`）；服务端只见 64 位 hex，拦不住短密码 |
| **跨账号串账**（借设备给亲友后登录别的账号） | 中 | `syncMeta.boundUserId` 分辨换号；换号且本机有数据时先询问，默认不并入 |
| 未成年人被过度收集诱导 | 低 | 不注册即可全功能使用；注册入口在家长设置页，孩子路径完全不涉及 |

## 3. 监护人权利落实

- 查阅 / 导出：设置 → 数据备份 → 导出（完整 JSON）
- 删除本机：设置 → 清空训练数据（双闸确认）
- 断开云端：设置 → 云同步 → 退出登录（本机数据不动）
- 删除云端账号与记录：一期无自助删号 UI，需人工处理。**可达渠道**：
  https://github.com/myacelw/focal-quest-app/issues （与隐私政策页 `privacy.contact` 同一口径——
  若无可达渠道，"监护人权利"等于没落实）

## 4. 结论

在"不收集身份信息 + 不注册即全功能 + 本地优先"的设计下，残余风险可接受。
**再评估触发条件**：开放注册、接入邮件/短信、加入任何第三方 SDK、启动商业化。
